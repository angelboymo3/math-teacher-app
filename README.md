# 풀이과정 · 수학 수업 노트

고등학교 수학 교사의 한 학기 수업 운영을 한곳에 모으는 웹앱입니다. 대학 수업 기말 과제이자 실제 수업을 위한 도구로 발전시킵니다.

## 첫 버전

평가 계획 / 수행평가 / 수업자료 / 정기고사 / 세특 기록의 5개 탭과 빈 화면을 제공합니다. 탭을 클릭하거나 키보드 방향키, Home, End로 이동할 수 있습니다. 주소 끝에 선택한 탭이 남아 새로고침·뒤로 가기에도 사용할 수 있습니다.

현재는 데이터를 입력하거나 저장하지 않습니다. JSON 내보내기·가져오기 버튼은 다음 단계 안내와 함께 비활성화되어 있습니다. 평가 계획 작성, 자료 관리, 학생 기록, 브라우저 저장과 실제 백업 기능은 다음 단계에서 구현합니다.

## 열어 보기

- 공개 주소: https://angelboymo3.github.io/math-teacher-app/
- 내 컴퓨터: 내려받은 폴더의 `index.html`을 브라우저로 엽니다.
- 추가 프로그램 설치나 파일 변환 없이 HTML(화면 구조), CSS(모양), JavaScript(탭 이동)만으로 동작합니다.
- JavaScript가 꺼져 있으면 평가 계획의 안내 화면만 표시됩니다.

## 개인정보와 백업

이 저장소와 배포 사이트는 공개용입니다. 실제 학생 이름, 성적, 세특, 비밀 키를 코드·문서·캡처·Git 기록에 넣지 않습니다. 시험 자료가 필요하면 “학생 01” 같은 가상 자료만 사용합니다. 현재 버전은 학생 자료를 포함하지 않으며 외부 분석 도구, 외부 글꼴, 데이터 전송 기능을 사용하지 않습니다.

다음 단계의 저장 공간은 localStorage(사용 중인 브라우저 안의 저장 공간)입니다. 다른 기기와 자동 동기화되지 않으며 브라우저 데이터 삭제 시 사라질 수 있습니다. JSON(저장 내용을 옮겨 담는 텍스트 파일)으로 백업하고 복원하는 기능을 함께 구현할 예정입니다. 개인정보가 포함된 백업은 저장소 밖의 별도 안전한 위치에 보관해야 합니다.

`.gitignore`는 `node_modules/`, `.env`, `.env.*`, `*.pem`, `*.key`, `backups/`를 업로드 대상에서 제외합니다. 모든 개인정보를 자동 감지하는 장치는 아니므로 커밋 전에 파일 내용을 확인합니다.

## GitHub Pages 설정

1. GitHub 저장소에서 Public 표시를 확인합니다.
2. Settings → Pages를 엽니다.
3. Build and deployment → Source에서 Deploy from a branch를 선택합니다.
4. Branch를 main, 폴더를 /(root)로 선택하고 Save를 누릅니다.
5. 배포가 끝나면 Visit site로 실제 화면을 확인합니다. 실패 시 Actions에서 실행 결과를 확인합니다.

이후 main에 푸시하면 자동으로 다시 배포됩니다. 커밋은 변경 이력 저장, 푸시는 GitHub 업로드를 뜻합니다. 작업 완료 시 확인 후 커밋·푸시합니다.

## 구성과 확인 항목

- `index.html`: 5개 탭, 빈 화면, JavaScript 비활성 안내
- `assets/`: 스타일과 탭 이동 코드
- `screenshots/01-first-version.png`: 첫 화면 캡처
- `CHECKLIST.md`: AI 초안과 직접 수정한 내용의 비교표(현재 표 머리만 제공)

컴퓨터와 너비 360px 모바일 화면, 탭 클릭·키보드 이동, 새로고침·뒤로 가기, 잘못된 탭 주소, 비활성 백업 버튼, JavaScript 비활성 및 초기화 오류 안내를 확인합니다. 초기화에 실패하면 새로고침 안내를 표시하며 데이터는 변경하지 않습니다.
